# reqlinqo Pilot Process

## Offer
reqlinqo is a managed pilot for home service / trade businesses that want:
- faster lead response
- fewer missed jobs
- urgent-job visibility
- cleaner callback / follow-up handling
- a protected workspace for their team

## Who it is for
Good fit:
- plumbing
- HVAC
- electrical
- roofing
- restoration
- garage doors
- landscaping
- detailing
- similar service businesses with inbound lead flow

## Sales / onboarding flow
1. Prospect lands on site
2. Prospect books a demo
3. Demo request creates:
   - a lead in reqlinqo
   - a provisioned workspace
   - a client login
4. Admin reviews the request
5. Admin decides whether to move pilot to active
6. Intake workflow is configured for the client
7. Client receives login credentials
8. Pilot begins

## Pilot statuses
- `provisioned` → workspace created, not fully activated yet
- `active` → pilot live and client is using it
- `archived` → pilot paused, ended, or retired

## What the client gets during pilot
- protected client workspace
- lead review queue
- drafted replies
- urgent-job visibility
- callback tracking
- follow-up visibility
- source / pipeline visibility

## What admin does during pilot
- review demo requests
- activate/archive workspaces
- reset client credentials
- view client portals
- monitor lead flow quality
- tune workflow rules

## Suggested delivery process
### Week 0 - Setup
- confirm trade/business workflow
- confirm lead sources
- confirm reply expectations
- confirm urgent-job criteria
- activate workspace

### Week 1 - Intake and tuning
- connect initial intake
- review first batch of leads
- tune reply style and routing
- verify portal usability

### Week 2+ - Pilot optimization
- review missed opportunities
- tune source handling
- tune follow-up expectations
- track client feedback

## Pilot success criteria
A pilot is successful if it improves one or more of these:
- response speed
- urgent-job visibility
- callback follow-through
- fewer missed inquiries
- cleaner office workflow
